# Project AI Rules — AIA Website

## Trailing Slash Policy (Permanent Rule - DO NOT CHANGE)
- **Course Page URLs ONLY** (`/cfe-curriculum`, `/cia-curriculum`, `/cia-challenge-curriculum`, `/cams`, `/cisa`) must **NEVER** have a trailing slash.
- **All other URLs** (Home `/`, `/about-aia/`, `/blogs/`, `/blogs/:slug/`, `/alumni-network/`, `/contact/`, `/enroll-now/`, `/corporate-training/`, `/policies/`, `/terms-and-conditions/`, `/passout-stories/:slug/`, free resources, etc.) must **ALWAYS** have a trailing slash.
- This rule is absolute and permanent across all sitemaps, canonical links, routers, navigations, redirects, and internal links in every future edit.

## Git Operations
- **Do Not Automate Git Commits or Pushes**: Never run `git commit` or `git push` commands automatically. The user will manually review, stage, commit, and push all code changes themselves.

## Development Principles
- **Apply Ponytail Minimalism**: Read existing files first, reuse before creating, use the minimum that works. Never write a new component, file, or utility if an existing one can be reused or extended with a prop or argument.
